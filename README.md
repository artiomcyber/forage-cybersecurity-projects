### Case 01 — Security awareness and phishing

The Mastercard simulation involved reviewing phishing indicators, assessing campaign-level outcomes and designing a training presentation for HR and Marketing. The email exercises were conducted **within the educational simulation**, not against external targets.

**Outcome:** A documented campaign analysis and [security-awareness training deck](01-mastercard-cybersecurity/security-awareness-training-HR-Marketing.pptx).

### Case 02 — Log investigation

The Deloitte simulation included web request analysis, identifying repeat access patterns and reconstructing what occurred when a session expired and requests were denied.

**Outcome:** A written incident timeline supported by four [log investigation screenshots](02-deloitte-cyber/README.md#-evidence-screenshots).

### Case 03 — Incident impact and risk assessment

The Datacom simulation covered a hypothetical ransomware incident and a separate retail security risk assessment. The reports include business-impact framing, prioritization and control recommendations based on the supplied cases.

**Outcome:** [Incident impact report](03-datacom-cybersecurity-operations/Orion%20Health%20Security%20Breach%20Impact%20Report.docx) and [risk assessment](03-datacom-cybersecurity-operations/RetailNova%20Risk%20Assessment.docx).

## Methods and skills

Threat identification · Phishing analysis · Security awareness · Log review · Incident timelines · Business impact assessment · Risk registers · Risk treatment recommendations · Written security reporting.

All employee populations, events and security findings in these simulations relate to fictional training scenarios. Individual project documentation provides the detailed tasks and evidence.
